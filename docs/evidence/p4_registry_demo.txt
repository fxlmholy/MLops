# บังคับ promote v2 → API reload → rollback กลับ v1 → API reload
$ python -m src.registry promote 2
[registry] champion: v1 → v2
$ curl -X POST localhost:8000/reload
{"status":"reloaded","from_version":"1","to_version":"2"}
$ python -m src.registry rollback
[registry] rollback champion: v2 → v1  (เรียก POST /reload ที่ API เพื่อโหลดใหม่)
$ curl -X POST localhost:8000/reload
{"status":"reloaded","from_version":"2","to_version":"1"}
$ python -m src.registry status
v1   champion    run=lightgbm_default
v2   archived    run=linear_regression
